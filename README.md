### About me

I build real-time web tools that work the same on a phone and a desktop. I like small, useful projects that people can open in a browser and use right away.

### What I'm building

**[CodeRelay](https://coderelayy.onrender.com)** is a shared coding room. Create a workspace, share the QR code or link, and your whole team edits the same code live. It can run JavaScript and Python in the browser, preview HTML and CSS, lock editing, and save workspaces with encryption.
